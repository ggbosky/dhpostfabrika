Zdroje záběrů a klíče

  • Wikimedia Commons – videa s volnou licencí, aplikace je umí rovnou použít. Zdarma, bez klíče.
  • Internet Archive – náhled a odkaz; soubor stáhneš ručně (archiv nedovolí načtení z cizí stránky) a importuješ. Zdarma.
  • Web přes AI (YouTube, NHL.com, iVysílání ČT, IIHF…) – hledá v jazycích, které zvolíš; jen ke sledování a jako zdroj. Potřebuje AI klíč (Claude nebo Gemini).
  • YouTube Data API – volitelné, přesnější hledání s délkou videa, licencí a časovými značkami. Bezplatný klíč z Google Cloud (10 000 jednotek/den ≈ 100 hledání). Videa z YouTube aplikace nestahuje.
  • Vlastní soubory – záběry, ke kterým máš práva (licence ČT, klub, NHL…), přetáhni do kroku Záběry.
Jak získat YouTube klíč zdarma
  1. console.cloud.google.com → nový projekt.
  2. APIs & Services → Library → YouTube Data API v3 → Enable.
  3. Credentials → Create credentials → API key. Doporučeno omezit na web ggbosky.github.io.

Aktuální styl

🎙️ Volitelně: ElevenLabs přes API klíč

Nemusíš – hlas z ElevenLabs jde použít i bez klíče: v Reels → krok Hlas zkopíruj text, vygeneruj ho na webu ElevenLabs a nahraj MP3 zpátky. Klíč jen ušetří to přenášení.

Reels pak namlouvá tvůj hlas z ElevenLabs (např. „Kuba – Czech Social Media“) místo zdarma hlasu Jirka. Hlas musí být v ElevenLabs v sekci My Voices (u knihovních hlasů klikni na Add to my voices).

  1. V ElevenLabs otevři Developers → API Keys a vytvoř klíč (stačí oprávnění Text to Speech + Voices: read).
  2. Vlož ho sem a klikni Uložit a načíst hlasy – Kuba se vybere sám.

Výchozí nastavení odpovídá tvé ukázce (model v4, stabilita 50 %, podobnost 75 %). Každé namluvení stojí znaky z tvého ElevenLabs plánu – 45s reel je zhruba 600–900 znaků. Klíč zůstává jen v tomhle prohlížeči.

✨ AI pomocník (volitelné)

AI navrhuje texty, carousely, scénáře reels, hledá témata a ověřuje fakta. Stačí jeden klíč – když vyplníš oba, pracuje Claude a Gemini je záloha. Bez klíče aplikace funguje dál, jen bez tlačítek ✨.

Claude (Anthropic) – doporučeno

  1. V Anthropic Console otevři API keys → Create key a klíč zkopíruj (začíná sk-ant-).
  2. Vlož ho sem a klikni Uložit a ověřit. Zůstane jen v tomhle prohlížeči a posílá se jen na api.anthropic.com.

Platí se z kreditu v Anthropic Console (předplatné Claude.ai sem nepatří). Jeden návrh postu stojí řádově korunu, hledání témat s webem pár korun.

Google Gemini – zdarma (záloha)

  1. Otevři aistudio.google.com/apikey a přihlas se Google účtem.
  2. Klikni Create API key a klíč zkopíruj.
  3. Vlož ho sem a ulož. Zůstane jen v tomhle prohlížeči a posílá se jen Googlu.

Zdarma je asi 20 návrhů denně na model (aplikace sama střídá modely), limit se obnovuje v 9:00. Fotky hledá na Wikimedia Commons – tam jsou fotky, které se smí použít s uvedením autora; ten se do popisku přidá sám.
